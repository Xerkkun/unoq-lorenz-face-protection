Experimental boundaries

Box--frame alignment: the detector classification and callback JPEG do not expose a shared source-frame identifier. The displayed number is local to the callback; it does not prove temporal alignment, detector recall, or absence of dropped source frames.

Network and secrets: run Network Mode only on an isolated, trusted laboratory network. Never place the master key in this page, a URL, app.yaml, logs, CSV files, or the run manifest; inject it into the process environment and rotate it for every run.

In M3--M4, the operational intent is to avoid showing plaintext inside accepted boxes; verify the preview and packet store independently. M0--M2 are insecure ablations and can expose source information, so the interface marks them with a red warning.
